# 同义替换消消乐 · Synonym Pop

一个可以静态部署的英语同义替换练习游戏。通过听力配对、阅读配对和雪球复习，把词组复习融入岛屿探索。

完整运行页面、题库、1,815 段练习录音和本地字体均已包含。无需后端服务、数据库或第三方 JavaScript 框架。

## 快速开始

下载或克隆本仓库，在仓库目录运行：

```sh
python3 -m http.server 8080 --directory web
```

打开 <http://localhost:8080/>。运行页面已构建完成；Python 仅用于本地提供静态文件。

## 玩法

- 听力配对：听录音，选择对应的同义表达；支持重听、慢速和提示。
- 阅读配对：阅读表达并匹配原文说法，配合中文释义和语境。
- 岛屿地图：动态背景、小径和建筑随关卡进度展示。
- 连击反馈：连击特效、分级音效、通关庆祝和界面转场。
- 雪球复习：自动随机安排正反听力方向，由通用机器人投掷雪球；没有每日次数或五组上限。
- 进度保存在当前浏览器的 `localStorage`，不上传服务器；换设备或清理浏览器不会自动同步。
- 支持系统的减少动态效果设置；音频需要用户点击后播放。

## 修改与构建

需要 Python 3.9 或更新版本，不需要安装 Python 依赖。

```sh
python3 build.py
python3 verify.py
```

| 路径 | 内容 |
| --- | --- |
| `web/index.html` | 可直接部署的完整运行页面 |
| `web/audio/` | 1,815 段 MP3 练习录音 |
| `web/assets/` | 通用机器人 SVG、本地字体及字体许可证 |
| `source/template.html` | 界面、交互、地图、动效与音效源码 |
| `source/rows.json` | 听力源记录：书册、来源、题号、题目表达、原文表达、中文 |
| `source/rrows.json` | 阅读源记录：书册、Test、Passage、题号、题目表达、原文表达、中文、语境 |
| `source/audio-map.json` | 表达与录音相对路径的对应关系 |
| `source/content-review.json` | 修订和暂缓出题记录 |
| `build.py` | 从源文件构建运行页面 |
| `verify.py` | 构建一致性、资源路径、录音覆盖与内容状态检查 |

源记录顺序参与生成学习记录 ID，修改已有题库时应保持顺序。表达中的 `=` 会展开为多个原文说法。审校文件 `row` 是从 0 开始的源记录索引。

目前共 336 关；可用听力 981 条、阅读 2,675 条。175 条源记录展开后的 179 个词条暂缓出题，继续从正式题目、干扰项和复习池中过滤；修订状态保留在 `content-review.json` 中。

## 部署

把 `web/` 内全部文件上传到任意静态网站服务，并保留 `audio/`、`assets/` 相对目录。入口为 `index.html`，也支持部署在子路径下。网页没有账号登录、学习记录云同步或服务端功能。
